# IDEAS — Proposed and Evaluated Opportunities

## How to Use This File

Each idea is evaluated using the VANGUARD opportunity filter:

- **Market:** Large, growing, painful, paying?
- **AI Hunger:** Does AI create a 10x advantage?
- **Solopreneur Fit:** Can one person + agents build the first version?
- **Speed:** Can we validate quickly?
- **Revenue:** Can customers pay early?
- **Scalability:** Can it grow without proportional human effort?
- **Defensibility:** Can we build a durable moat?
- **Strategic Value:** Does it move us toward $1B?
